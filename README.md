📖 Descrição do Projeto
Olá! Que alegria ter você por aqui! ✨

Este é o repositório do meu portfólio pessoal, um projeto que desenvolvi para apresentar minha jornada, habilidades e projetos como Desenvolvedor Frontend. Foi criado com muito cuidado para oferecer uma experiência de usuário agradável e intuitiva, refletindo minha paixão por criar interfaces memoráveis.

Clique aqui para ver o projeto ao vivo! https://andersonrafael.github.io/Portfolio/

🚀 Funcionalidades Principais
O site está organizado em várias seções para facilitar a navegação:

🏠 Home: Uma seção de boas-vindas com uma breve apresentação.

👤 Sobre: Um pouco mais sobre mim, minhas paixões e minha carreira como desenvolvedor.

🎓 Jornada: Detalhes sobre minha formação acadêmica e experiências profissionais relevantes.

🛠️ Skills: Uma visão geral das minhas habilidades técnicas e profissionais, com barras de progresso que mostram meu nível de confiança em cada uma.

📫 Contato: Um formulário simples e funcional para que recrutadores e clientes possam entrar em contato diretamente.

📱 Responsividade: O layout foi pensado para se adaptar perfeitamente a diferentes tamanhos de tela, de desktops a celulares.

💻 Tecnologias Utilizadas
Este projeto foi construído do zero, utilizando as seguintes tecnologias que amo trabalhar:

HTML5: Para a estrutura semântica do conteúdo.

CSS3: Para a estilização, animações e design responsivo.

JavaScript: Para a interatividade, como o menu de navegação e os efeitos de scroll.

Boxicons: Para os ícones modernos e elegantes.

Google Fonts: Para a tipografia refinada do site.
